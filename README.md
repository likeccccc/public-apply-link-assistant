# 公开投递链接助手 v1.5

适用于 `givemeoc.com` 招聘列表的 Chrome 扩展。网页右下角的绿色“投 · 查投递入口”浮卡负责搜索：点击开始、按住拖动位置、再次点击停止。点击工具栏图标会打开设置小弹窗。v1.5 新增“链接打开方式”，可选当前浏览器或 Microsoft Edge。每查完一家，候选投递链接或“手动搜索”按钮会立即显示在对应企业行。

## 朋友首次安装

1. 在 GitHub 仓库点击 **Code → Download ZIP**，解压后找到其中的 `extension` 文件夹。
2. 在 Chrome 打开 `chrome://extensions/`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择 `extension` 文件夹。不要直接选择 ZIP 文件或外层仓库文件夹。
3. 点击工具栏里的扩展图标，在小弹窗里填写自己的 API Base URL、模型名称和 API Key；密钥**不随本仓库分发**，每个人需使用自己的凭据。若使用非内置 API 域名，点击“检查并授权 API 域名”。
4. 打开 `https://givemeoc.com/` 的招聘列表，点页面右下角的绿色浮卡。

## 已安装用户更新

1. 用新版文件覆盖**原来的扩展文件夹**，在 `chrome://extensions/` 点“重新加载”，然后刷新招聘网页。不要卸载原扩展或换文件夹，否则旧 API Key 所在的扩展本地存储可能无法读取。
2. 如需配置，直接点浏览器工具栏里的扩展图标，设置会在小弹窗中打开。API Base URL、模型名称、API Key、搜索范围、链接位置及打开浏览器都会立即保存，也可以点“保存全部设置”。弹窗失焦关闭后再打开，已输入的字段会恢复；原先的本地 Key 和选项沿用同一存储键。
3. 回到招聘列表，点绿色浮卡。默认搜索当前屏幕最多 12 家；设置里可选整页最多 50 家，链接可放在公司名称列或相关链接列。在 Windows 上选择 Microsoft Edge 后，插件新加的投递链接、来源链接和“手动搜索”都会通过 `microsoft-edge:` 协议打开 Edge；Chrome 可能提示确认打开外部应用。切换该选项也会立即更新已显示的插件链接，不必重新搜索。

新悬浮按钮只负责搜索和进度，不保存或传递 API Key。后台在每次查询时直接读取同一份扩展本地配置；Key 不会作为消息返回网页。若你使用自定义 API 域名，在设置页点“检查并授权 API 域名”。

相同 API 地址、模型和企业名称的结果缓存 24 小时，减少重复请求。逐家公司搜索可能产生多次模型请求和费用。只读取页面已显示的企业名称与简短岗位内容，不读取登录后、会员或验证码保护的字段。模型找到的入口属于候选链接，投递前请核对公司官网、岗位、招聘批次和截止日期；未找到入口时，“手动搜索”按钮只打开普通网页搜索，不消耗模型 Token。

如果更新后仍看到旧按钮，刷新招聘网页。若同时安装了另一份旧扩展，请在扩展管理页停用旧副本。API Key 保存在当前浏览器配置文件的扩展本地存储里，并非加密保险箱；共享电脑请谨慎使用。
